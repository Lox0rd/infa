<h1>Описание алгоритма функции read_words_to_array</h1>

<h>Функция read_words_to_array считывает слова из текстового файла и сохраняет их в упорядоченной структуре данных. Разберём алгоритм пошагово.
Входные и выходные данные</h>

# Входные параметры:
* filename — имя файла для чтения;</p>
* top_size — указатель на переменную, куда будет записано количество блоков в результате.

# Возвращаемое значение:
* указатель на трёхмерный массив (char***) — структура данных, содержащая отсортированные слова;
* NULL, если файл не удалось открыть.

# Шаг 1. Инициализация и проверка файла
* Открываем файл на чтение с помощью fopen.
* Если файл не удалось открыть, устанавливаем *top_size = 0 и возвращаем NULL.

# Шаг 2. Подготовка структуры данных
* Выделяем память для «верхнего» массива (top) с начальной ёмкостью cap = 10 блоков.
* Инициализируем *top_size = 0 (количество блоков пока равно нулю).
* Создаём буфер word[256] для временного хранения считываемого слова.

# Шаг 3. Пословное чтение файла
## В цикле while считываем слова из файла с помощью fscanf(f, "%255s", word):
* каждое слово копируется в динамически выделенную память (new_word);
* далее слово нужно вставить в структуру данных с сохранением сортировки.

# Шаг 4. Поиск позиции для вставки
## Для нового слова ищем позицию pos в «верхнем» массиве top:
* сравниваем new_word с первым словом каждого блока (top[pos][0]) с помощью strcmp;
* позиция pos — это индекс блока, куда должно попасть новое слово (или в новый блок в конце, если слово больше всех существующих).

# Шаг 5. Вставка в существующий блок

## Если найденный блок (pos < *top_size) существует:
<h1> Считаем количество слов в блоке (cnt), ища NULL‑маркер.</h1>
<h3>Если в блоке есть место (cnt < BOTTOM_SIZE):</h3>
<p>находим позицию ins внутри блока для сохранения сортировки;</p>
<p>сдвигаем слова вправо, чтобы освободить место;</p>
<p>вставляем new_word.</p>
<h3>Если блок переполнен (cnt == BOTTOM_SIZE):</h3>
<h2>делим блок пополам:</h2>
<p>создаём новый блок (new_block) для второй половины слов;</p>
<p>копируем вторую половину слов (half = BOTTOM_SIZE / 2) в новый блок;</p>
<p>обрезаем текущий блок, устанавливая NULL после первой половины;</p>
<h2>расширяем «верхний» массив top, если нужно (удваиваем cap и realloc);</h2>
<h2>сдвигаем блоки в top вправо, чтобы вставить новый блок;</h2>
<h2>увеличиваем *top_size;</h2>
<h2>определяем, в какой блок вставить new_word (в первый или второй), и вставляем его с сохранением порядка.</h2>

# Шаг 6. Создание нового блока

## Если нужно добавить слово в конец (pos == *top_size):
* При необходимости расширяем top (удваиваем cap и realloc).
* Создаём новый блок new_block с ёмкостью BOTTOM_SIZE + 1 (последний элемент — NULL).
* Помещаем new_word в начало блока, остальные элементы инициализируем как NULL.
* Добавляем блок в top и увеличиваем *top_size.

# Шаг 7. Завершение
* Закрываем файл fclose(f).
* Возвращаем указатель на структуру top.
